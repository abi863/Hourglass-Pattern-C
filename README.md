# Hourglass Pattern in C

## Description

This project prints an hourglass star pattern using nested `for` loops in C.

## Sample Output

```text
* * * * * * *
  * * * * *
    * * *
      *
    * * *
  * * * * *
* * * * * * *
```

## Concepts Used

* Nested `for` loops
* Pattern printing
* Spaces and stars
* Basic C programming

## How to Run

```bash
gcc hourglass.c -o hourglass.exe
./hourglass.exe
```

## Language

C
